# ESPCN: Image Super-Resolution using PyTorch

This repository contains a PyTorch implementation of the **Efficient Sub-Pixel Convolutional Neural Network (ESPCN)** for Image Super-Resolution. The model is designed to upscale low-resolution images to high-resolution while maintaining computational efficiency.

## 🚀 Overview
Unlike traditional methods that upscale the low-resolution image before feeding it into the network, ESPCN extracts feature maps in the low-resolution space and applies a **Sub-Pixel Convolution layer (`nn.PixelShuffle`)** at the very end to construct the high-resolution output. This makes the model significantly faster and more efficient.

## 📊 Dataset
This project uses the **DIV2K (DIVerse 2K resolution image dataset)**, a popular benchmark dataset for super-resolution tasks. 
- The dataset is automatically downloaded via the `kagglehub` API.
- Training samples are randomly cropped to `256x256` for High-Resolution (HR) targets.
- The Low-Resolution (LR) inputs are generated by downscaling the HR images to `128x128` using Bicubic interpolation.

## 🧠 Model Architecture
The network is a fully convolutional neural network consisting of:
1. `Conv2d (3 -> 64)` + ReLU
2. `Conv2d (64 -> 32)` + ReLU
3. `Conv2d (32 -> 3 * scale_factor^2)`
4. `PixelShuffle(scale_factor)` -> Rearranges elements in a tensor of shape `[C*r^2, H, W]` to a tensor of shape `[C, H*r, W*r]`.

*Current Scale Factor: 2x*
